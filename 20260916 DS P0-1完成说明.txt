三、AgentState 最终结构
----------------------------------------------------------
@dataclass
class AgentState:
    # 核心标识
    name: str
    owner: str

    # 直接映射（源自 main.data）
    location: str
    wallet: float
    affection: int
    is_following: bool
    is_dating: bool
    is_working: bool

    # 推导字段
    current_activity: str

    # 可选 / 占位字段
    current_goal: Optional[str] = None
    mood: int = 70
    energy: int = 70
    social_need: int = 30
    stress: int = 20

    # 元数据：字段来源标记
    _meta: Dict[str, str]

----------------------------------------------------------

----------------------------------------------------------
字段              来源                    类型

name              canonical_ai_name       direct
owner             owner_of_ai + 反向查找   direct
location          data["ai_location"]     direct_map
wallet            data["wallets"]         direct_map
affection         data["affection"]       direct_map
is_following      data["ai_follow"]       direct_map
is_dating         data["dates"]           direct_map
is_working        data["work_sessions"]   direct_map
current_activity  _derive_activity()      derived
current_goal      —                       none (None)

九、T2 加固说明（迭代记录）
----------------------------------------------------------
问题：main.canonical_ai_name() 找不到时返回原字符串而非 None，
      导致 get_agent_state("Ghost") 返回"幽灵对象"而非 None。

解决：在 agent/state.py 中新增显式存在性检查：
      在获得 canonical 后，再遍历 data["user_ais"] 验证，
      未找到则立即 return None。

改动范围：仅 agent/state.py 内部，不影响其他任何文件。
