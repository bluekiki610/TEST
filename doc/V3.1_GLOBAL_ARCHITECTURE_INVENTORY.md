## 2. import / caller 关系

### 2.1 核心导入图（后端）

```
main.py
├── 无 import 任何 ext（ext 由 _load_extensions 动态加载）
└── 提供：data, save_data, now_str, room_time, strip_emoji, canonical_*,
         owner_of_ai, is_admin, find_building_of_room, resolve_building,
         full_room_name, room_exists, can_access_room, add_trail,
         append_timeline, append_visited, track_visit, track_note,
         split_sms, ai_integration_enabled, ... + 全部 Pydantic 模型

ext_*.py
├── 都通过 `import main as m` + `from main import (...)` 使用 main 工具
├── 部分通过 `from ext_memory import enqueue_event`（直接 import）
├── 部分通过 `m.xxx` 使用被其他 ext 挂载的函数（隐式跨模块调用）
└── 都在 `setup(app, data, helpers)` 中注册路由

agent/*.py
├── state.py 只依赖 main（只读）
├── event.py 无依赖
├── event_adapter.py 依赖 event
└── runtime.py 依赖 event + state
```

    // new_notification → checkBell()
    // ping → 心跳

- 失败 5s 后自动重连
